## 📌 Projeto em Destaque

### 📊 [Predição de Turnover em People Analytics](https://github.com/Dudiesz/employee-retention-machine-learning)
* **O Problema:** Identificar antecipadamente padrões e fatores determinantes para o desligamento voluntário de colaboradores.
* **A Solução:** Desenvolvimento de um modelo preditivo baseado em **Random Forest**, otimizado para a métrica de **Recall** e estruturado sob a metodologia **CRISP-DM**.
* **Stack:** Python, Scikit-Learn, Pandas, Matplotlib / Seaborn.
